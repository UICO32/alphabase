# 点阵背景渐隐逻辑

## 核心文件

- `packages/editor/src/lib/components/default-components/DefaultGrid.tsx` — 渲染组件
- `packages/editor/src/lib/options.ts` — gridSteps 配置
- `packages/utils/src/lib/number.ts` — modulate 工具函数

## 渐隐核心

```typescript
const opacity = z < mid ? modulate(z, [min, mid], [0, 1]) : 1
```

- `z` 是当前缩放级别
- `min` 是该网格层开始出现的缩放阈值（opacity 从 0 开始上升）
- `mid` 是该网格层完全显示的缩放阈值（opacity 达到 1）
- 缩放 < min → opacity 为 0（不可见）；min 到 mid 之间 → 线性插值 0→1；>= mid → 完全不透明

**渐隐基于缩放级别，不是距离中心的距离。** 同一缩放级别下所有点共享相同透明度。

## 多层网格叠加

4 层网格，每层间距不同，缩放区间重叠：

```typescript
gridSteps: [
  { min: -1,   mid: 0.15, step: 64 },  // 极远：64px 间距
  { min: 0.05, mid: 0.375, step: 16 },  // 中等：16px 间距
  { min: 0.15, mid: 1,    step: 4 },    // 正常：4px 间距
  { min: 0.7,  mid: 2.5,  step: 1 },    // 极近：1px 间距
]
```

缩放变化时，粗网格淡出、细网格淡入，形成平滑的多分辨率过渡。

## 渲染方式

SVG `<pattern>` + `<circle>` 绘制，每个 gridStep 生成一个 pattern：

```typescript
const s = step * size * z          // 实际间距
const gxo = (0.5 + x * z) % s     // x 偏移取模，平移时保持对齐
const gyo = (0.5 + y * z) % s     // y 偏移取模
<circle cx={gxo} cy={gyo} r={1} opacity={opacity} />
```

最后用 4 个 `<rect>` 覆盖全画布，分别引用各 pattern URL，多层叠加。

## modulate 工具函数

```typescript
function modulate(value, rangeA, rangeB, clamp = false) {
  const [fromLow, fromHigh] = rangeA
  const [v0, v1] = rangeB
  return v0 + ((value - fromLow) / (fromHigh - fromLow)) * (v1 - v0)
}
```

将 value 从 rangeA 线性映射到 rangeB。

## 总结

4 层不同密度的点阵，每层在特定缩放区间内通过 modulate 线性插值 opacity 实现淡入淡出，层间重叠过渡，实现缩放时点阵密度的平滑切换。
